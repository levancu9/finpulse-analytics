# FinPulse Analytics

An internal banking analytics and operational intelligence platform designed for high-throughput financial data visualization and risk verification.

## Core Features
- **Real-time Financial Dashboards**: Visualizing transaction flows, liquidity metrics, and operational performance.
- **Natural Language Analytics**: Text-to-query reasoning over core banking and transactional logs powered by Claude.
- **Automated Compliance & Risk Detection**: Auditing multi-step business logic to flag operational conflicts and anomalies.
- **Enterprise-grade Reporting**: Modular UI components for continuous audit and operational monitoring.

## Tech Stack
- Frontend: Next.js / React, TailwindCSS, Charting libraries
- Backend / Analytics: Python / FastAPI, PostgreSQL
- AI / LLM Engine: Anthropic Claude (Sonnet / Opus)
